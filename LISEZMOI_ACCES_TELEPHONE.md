# 📱 Comment ouvrir Sama Daara sur votre Téléphone

Pour afficher et tester le site sur votre téléphone en direct depuis votre ordinateur :

---

### 🚀 Méthode 1 : En 1 Clic (Recommandée)
1. Double-cliquez sur le fichier **`Lancer_Sur_Telephone.bat`** (ou lancez `Lancer_Sur_Telephone.ps1`).
2. Le serveur d'application démarre automatiquement.
3. La page [index.html](file:///c:/Users/Cheikh%20khady/OneDrive/Documents/PROJET/index.html) s'ouvre avec le **Code QR**.
4. Ouvrez **l'appareil photo de votre smartphone** (iPhone ou Android) et scannez le Code QR à l'écran.

---

### 🌐 Méthode 2 : Par l'Adresse Directe
1. Assurez-vous que votre téléphone est connecté au **même réseau Wi-Fi** que votre ordinateur.
2. Ouvrez Chrome ou Safari sur votre téléphone et entrez :
   ```text
   http://10.71.231.110:3000/
   ```

---

### 📂 Fichiers créés et organisés pour vous :
- **[index.html](file:///c:/Users/Cheikh%20khady/OneDrive/Documents/PROJET/index.html)** : Portail avec le Code QR, le lien cliquable, le bouton copier et les instructions.
- **[index.htlm](file:///c:/Users/Cheikh%20khady/OneDrive/Documents/PROJET/index.htlm)** : Fichier de redirection automatique (au cas où vous tapez le nom avec cette orthographe).
- **[Lancer_Sur_Telephone.bat](file:///c:/Users/Cheikh%20khady/OneDrive/Documents/PROJET/Lancer_Sur_Telephone.bat)** : Détecte l'IP Wi-Fi en temps réel, lance le serveur Vite et affiche le QR Code.
- **[Ouvrir_Sur_Mon_Telephone.url](file:///c:/Users/Cheikh%20khady/OneDrive/Documents/PROJET/Ouvrir_Sur_Mon_Telephone.url)** : Raccourci direct vers l'adresse réseau.
- **[Ouvrir_Application_Sama_daara.url](file:///c:/Users/Cheikh%20khady/OneDrive/Documents/PROJET/Ouvrir_Application_Sama_daara.url)** : Raccourci direct pour ouvrir sur votre PC (`localhost:3000`).

---

### 💡 En cas de problème de connexion sur le téléphone :
- **Même réseau Wi-Fi** : Vérifiez que le PC et le téléphone ne sont pas sur deux réseaux différents (ex: données mobiles 4G/5G vs Wi-Fi maison).
- **Pare-feu Windows** : Si la page charge à l'infini sur le téléphone, assurez-vous que votre réseau Wi-Fi est défini sur *Réseau privé* dans les paramètres Windows.
